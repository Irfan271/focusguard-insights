# FocusGuard Productivity Classifier — Model Card

## Purpose

This model demonstrates an end-to-end machine-learning pipeline for
classifying app-usage records into three productivity categories:

- Productive
- Moderate
- Distracted

It is intended as a portfolio project demonstrating data processing,
feature engineering, model training, evaluation, metadata tracking, and
deployment.

## Important limitation

The `productivity_label` target is generated by rules that use the same
underlying inputs available to the model, including screen time, study
time, sleep, notifications, and app category.

As a result, the model can reconstruct those rules almost perfectly.
The reported accuracy and F1-score therefore reflect **label leakage**,
not real-world predictive performance.

This model should not be interpreted as a validated predictor of a real
person’s productivity.

## Data

- Source: Synthetic dataset
- Grain: One row per app-usage record
- Users: 50 synthetic users
- Dates: 90 consecutive days
- Records: 2,700 app-usage rows
- Classes: Productive, Moderate, Distracted

## Features

The model uses:

- App usage duration
- Session count
- Notification count
- Hour of day
- Study time
- Sleep duration
- Daily total screen time
- Daily total study time
- Weekend indicator
- Notifications per session
- Usage per session
- One-hot encoded app category

## Training and evaluation

The final classifier is a `RandomForestClassifier`.

Two evaluations are recorded:

1. **User-day grouped split**  
   All records belonging to the same user and date are kept together in
   either training or testing. This prevents user-day leakage.

2. **Future-date holdout**  
   The model trains on the earliest 80% of dates and evaluates on the
   latest 20% of dates. This tests temporal generalization within the
   synthetic dataset.

Both evaluations report high scores because the labels are deterministic
rules derived from model inputs.

## Intended use

This project is suitable for demonstrating:

- Reproducible ML workflow design
- Feature engineering
- Grouped and temporal evaluation
- Model artifact and metadata persistence
- Streamlit dashboard deployment

## Not intended use

This project should not be used to:

- Diagnose attention disorders
- Make employment, academic, or clinical decisions
- Claim real-world productivity prediction
- Replace self-reported wellbeing or professional assessment

## Deployment

The trained classifier, scaler, feature-column list, and metadata are
saved in the `models/` directory. The Streamlit dashboard loads these
artifacts to generate predictions from user-entered daily summaries.
